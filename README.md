Smart To-Do & Task Management Application

A simple full-stack web application built as a project to manage daily tasks, projects, priorities, and progress.

About the Project

This project was created as a first full-stack web development experience. The main goal was to build a practical and user-friendly task management system where users can register, log in, create tasks, organize them into projects, assign priorities, add labels, and track progress from a dashboard.

The project also helped in understanding how frontend, backend, database, and authentication work together in a real application.

 Features

- User registration and login
- JWT-based authentication
- Dashboard overview
- Create, update, delete, and view tasks
- Project or list management
- Task priority, status, and due dates
- Labels and tags
- Reminders
- Comments on tasks
- Analytics summary

Tech Stack

Learning Outcome

This project was a valuable learning experience because it was the first time building a complete full-stack web application from scratch. It improved understanding of:

- API creation using Express.js
- Database design using MySQL
- User authentication using JWT
- Connecting React frontend with backend APIs
- Managing application state and components
- Organizing a real-world project structure
- Debugging frontend and backend integration issues

How to Run the Project

Backend
1. Open the backend folder in terminal.
2. Install dependencies using `npm install`.
3. Configure the `.env` file.
4. Start the backend server using `npm start` or `nodemon server.js`.

Frontend
1. Open the frontend folder in terminal.
2. Install dependencies using `npm install`.
3. Start the React app using `npm start`.
